# PLL 抖动：实板因果对照（2026-10-30）

## 结论

在本次 500 rpm、约 23.6 V、0.8 A 启动命令的短时工况下，实板对照支持：

**当前硬 sign SMO 与滤波反馈路径产生观测器极限环；反电动势纹波进入电压型鉴相器，
再通过 PLL 比例项放大为原始速度纹波，并进入控制角输出。**

不再仅凭慢速串口相关性或主机模型判断。证据包含目标 MCU 自身的零输入实验、
真实电机 A→B→A 回切、同一控制周期内的内部信号快照及离散方程复核。
这确认的是当前工况的主导机制，不是所有工况、所有硬件噪声的唯一根因。

## 采集与安全边界

- 目标：NS800RT7P65，J-Link SN `4294967295`；原库浮点 v3.1.0。
- 每个 20 kHz ADC ISR 在高环之后保存一次快照；9 s 时触发，1024 点，共 51.2 ms。
- 保存测量/预测 αβ 电流、注入、EMF、输入电压、PLL 误差/速度/角度、滤波速度、
  控制角、D/Q 电流、三相电流、母线、上周期 PLL 状态、ADC 次数、DWT 及故障标志。
- 单个样本 112 B，缓冲区含头部为 114752 B，位于 `.sram2`，不占用末尾核间邮箱。
- 不在高环打印。约 10.5 s 后发送停机，串口确认停机后才接 SWD；读取 GPIO23 为低，
  再额外清低并暂停 CPU 导出。没有暂停运行中的功率级。
- 诊断固件增加 3 A、ADC overflow 变化、50 µs ISR 执行时间和 12 s 运行期限的停机边界；
  原有保护保留，没有放宽判据。结构改动 C 只做栅极关闭的零输入测试。
- DWT 时间戳是 ISR 入口，不是 ADC 转换时间。采样周期名义为 50 µs，但 ISR 入口存在
  延迟变化，电机快照间隔约 19.6～83.9 µs；中位数为 50 µs。原始记录保留这一限制，
  不将本次试验当作严格实时性/WCET 验收。

## 1. MCU 零输入：不需要 ADC/PWM 干扰也会振荡

栅极关闭。另一个 SMO 实例在实际 MCU 的 ADC ISR 内运行，输入电流、电压**严格设为零**，
不接入控制器输出；先运行 20000 次，再记录 1024 次。它是目标 MCU 上的算法隔离实验，
不是电机静止时真实反电动势的物理测量。参数与当前控制器一致：
`T=50 µs, Rs=.2 Ω, Ld=Lq=.4 mH, h=6, Wc=800 rad/s, IntMax/Min=±10 A`。

| 对照 | 唯一机制改动 | α 估计反电动势范围 | 开关周期 |
| --- | --- | --- | --- |
| zero-A | 原版 | −1.319547～+1.319547 V | 24 点，833.33 Hz |
| zero-B2 | `sign(error)` → `sat(error/.8 A)` | 精确为 0 | 无振荡 |
| zero-A2 | 回切原版 | −1.319547～+1.319547 V | 24 点，833.33 Hz |
| zero-C | 保留硬 sign，仅将预测电流反馈改为直接开关注入 | 约 ±0.122351 V | 4 点，5000 Hz |

C 中低通仍用于导出的 EMF，只是不再位于预测电流反馈路径中。它没有消灭所有离散开关，
但去除了约 833 Hz、±1.32 V 的低频大幅振荡；因此不能把问题简单归咎于 PLL、ADC 或电机。
C 同时改变反馈取值/更新时序，不是“任何滤波反馈都不成立”的普遍性证明，更不是正式修复。

零输入窗口 FFT 频率间隔为 19.53125 Hz，最高频点为 839.84375 Hz；833.33 Hz 来自
实际注入波形上升沿的 24 点周期，而不是给 FFT 结果伪造更高精度。

## 2. 真实电机 A→B→A：改变硬开关，现象可逆

A1/A2 使用**逐字节相同的双 Bank 镜像**。B 只改变上述边界层；所有电机、PLL、
电流环、速度滤波、启动和板级参数均不变；三轮采样与安全诊断代码一致。
每轮 MCU 复位启动，500 rpm，0.8 A。表中标准差均来自各自 1024 点的同长度窗口。

| 实测量 | A1 原版 | B 边界层 | A2 回切原版 |
| --- | ---: | ---: | ---: |
| 原始 PLL 速度标准差 / rpm | 776.88 | 84.87 | 890.75 |
| 鉴相误差标准差 / V | 0.8134 | 0.08838 | 0.9327 |
| 扣除 `Kp×error` 后的速度标准差 / rpm | 9.69 | 8.06 | 12.23 |
| 原始速度/鉴相误差相关系数 | 0.999922 | 0.995486 | 0.999906 |
| 200～3000 Hz 原始速度纹波 RMS / rpm | 803.48 | 38.23 | 877.22 |
| 200～3000 Hz 控制角纹波 RMS / 电角度° | 1.969 | 0.1485 | 2.069 |
| 滤波速度标准差 / rpm | 6.58 | 8.49 | 9.24 |
| 全轮 ADC 相电流采样峰值 / A | 1.307 | 1.213 | 1.308 |
| ISR 执行时间观测峰值 / µs | 27.690 | 28.375 | 27.520 |
| ADC overflow | 0 | 0 | 0 |

B 的原始速度标准差相对两组 A 下降约 **89.1% / 90.5%**；200～3000 Hz 速度纹波
下降约 95%。恢复硬开关后，大幅纹波恢复。因此不是只给显示速度加滤波，也不是改了 PLL 增益。
原版电机鉴相误差/原始速度的主频点分别在 820 / 859 Hz 附近，EMF/注入也在约 800 Hz。
不将电机运行频率机械地等同于零输入的 833.33 Hz。

控制角结果是**软件输出纹波**，不是有编码器基准的真实转子角误差。
它证明问题进入了角度输出，但不能直接据此定量机械振动、转矩、损耗或效率。

滤波速度、D/Q 电流没有表现出一致而显著的全面改善，尤其 Iq 高频纹波未明显降低。
本次不据此宣布边界层方案已适合带载或已改善真实轴速。

## 3. 沿信号链的复核

- `h×sign(Ihat−I)` 与原版记录的注入值完全一致；B 的饱和函数重建误差小于 0.3 µV。
- 用输入电压、上一拍预测电流和上一拍**滤波 EMF**重建电流观测递推，最大偏差小于
  `6.2e-8 A`；不是仅从频谱形似判断反馈结构。
- 使用原版 sin/cos 查表重建 `−(Eα cosθ + Eβ sinθ)`，与采集鉴相误差偏差小于 `1.3e-7 V`。
- PLL 递推同样复核通过。2 极对、`Kp=200` 时比例贡献是约 **954.93 rpm/V**；
  扣除此贡献后，原版速度标准差从约 777/891 rpm 降为约 9.7/12.2 rpm。
- Welch 相干分析（256 点、50% 重叠），600～1200 Hz 的速度/误差加权相干系数大于 0.999999。
  这只是信号链验证；核心因果证据是零输入与 A/B/A 干预，不是相关性本身。

高频 RMS 的计算采用线性去趋势、Hann 窗、单边功率谱积分；计算代码和未经重采样的 RAM 数据
均随记录保存。短窗不适合证明低频稳定性、启动可靠性或长期统计显著性。

## 异常与排除记录

1. 初次零输入导出时，J-Link 将十进制长度当成十六进制，得到不完整文件；没有使用该文件。
   栅极仍关闭时改用明确的 `0x1c040` 长度导出，取得完整 114752 B 数据；两次日志均保留。
2. 另一会话曾同时改动电机适配文件，导致第二组编译失败。用户暂停并行工作后，在
   `/tmp/opencode/pll-board-20261030/isolated` 固定源码重新构建，A 的镜像与初次 A1 完全相同。
   初次 `diagnostic.patch` 在并行编辑时取得，不当作精确源码证据；归档的是经镜像一致性验证的
   诊断增量和完整诊断端口源文件。
3. 首次 B 固件下载后，尚未发送启动命令就反复复位，恢复保存的正常固件也同样复位；
   一次 SWD 读写失败。用户检查并完整断电重上电后恢复。异常原因未进一步定位，
   不计作边界层算法的运行结果，也不声称已证明是供电故障。
4. 完整上电后发现一次无效电流零点（约 −10 A 空闲读数），没有启动电机；在母线稳定后复位
   重校准，三相空闲电流均小于 0.2 A 才继续。脚本增加了该启动前检查。
5. A1 在这次完整重上电之前，B/A2 在之后；A2 同样复现大纹波，减轻但不能完全排除环境差异。
   本次只有一个 B 电机窗口，不宣称覆盖所有负载或具有长期重复性统计。

## 恢复结果

临时诊断改动未留在正常固件中。原工作区的 71 个快照文件（含已编译双 Bank 镜像）
与测试前 SHA-256 全部一致；不是用 Git HEAD 覆盖原先未提交工作。

- 正常 CPU0 镜像：`227ecb1c48d5be572810a7c1b69b9813c4f703d78d329bff97416366c29cdba5`
- CPU1/第二 Bank 镜像：`7bb640cccb8c1a06be9841bd71eab524069de711b63da275c3a3c96616a99ad8`
- 最终双 Bank 校验成功；GPIO23 为低；复位后保持 `idle / fault=none / ready=1 / cal=1 / target_rpm=0`。
- 最后复位恢复 DWT，空闲 ISR 当前周期计数为正；空闲电流有效。
- 启动布局、原版一致性/监督器和 IPC 回归通过。

## 数据与复算

- `manifest.json`：原始数据、固件、源文件和恢复校验值。
- `results.json`：全部计算结果，包括时间戳范围和方程重建误差。
- `zero-*/trace.bin`、`motor-*/trace.bin`：完整原始 RAM 导出，含 64 B 头部和 1024 个样本。
- 同目录 `trace.csv`：直接解码，不插值、不重采样；`uart.jsonl`/`export.log`：完整操作及 GPIO 证据。
- `diagnostic/`：临时诊断增量、完整端口、SMO 变体、缓冲区定义和测试脚本。
- `firmware/`：本次诊断 A/B/C 及恢复的正常镜像；**C 不得用于电机运行**。
- `incidents/`：启动复位、重新上电、早期校准和导出错误的记录。
