# SMO 直接注入反馈：修复与实板效果（2026-10-30）

## 实施内容

用户先审阅拟议 diff，再授权修改并实机验证。正常控制源码仅修改子模块浮点 v3.1.0
`Sguan_SMO.c` 的 `SMO_RUN()`：

1. 在积分前按当前保存的预测电流与本次测量电流计算硬 sign 注入 `Ex`。
2. 预测电流的反馈项使用 `Ex/Ld`，不再使用低通后的 `Output_Ex/Ld`。
3. 同一个 `Ex` 仍经过原有低通，输出 `Output_Ex` 给原版鉴相器/PLL。

保留硬 sign、`h=6`、`Wc=800 rad/s`、50 µs 周期、PLL `Kp=200 / Ki=10000`、
电机参数、IF、ADC/PWM 和电压限幅。没有加入边界层，不改公开结构体或接口。
因为注入从积分后移到积分前，这也改变了离散时序，不能称为纯粹换一个变量。

当前主工程采用另一次工作的精简接口：`status_schema=2`，6 字段/24 字节。
该接口及其 ADC/IPC 清理均保留，未恢复旧的 220 字节诊断状态。

## 实验方法

- 目标 MCU NS800RT7P65，J-Link SN `4294967295`，母线约 23.6 V；启动电流命令 0.8 A。
- 新鲜工作区快照保存到 `/tmp/opencode/sguan-direct-feedback-20261030/snapshot`，不使用 Git HEAD 覆盖未提交工作。
- 临时诊断只在 `isolated/` 构建副本中加入，公开 `motor status` 保持精简；
  独立 `diag` 命令发布私有诊断快照，不复用或扩大正式 IPC 状态结构。
- 原版 A、修正版 B 使用同样诊断；A1/A2/800 的双 Bank 固件完全相同，B1/B2/800 也完全相同。
  B 与 A 的控制算法差异仅为上述 SMO 修正；诊断标识分别为 0/2，不是边界层变体。
- 高环运行约 9 s 时，在同一个 ADC ISR 内连续保存 1024 点、名义 20 kHz，共 51.2 ms。
  电流测量/预测、注入、EMF、施加电压、PLL 状态、控制角、D/Q 电流、三相电流和 DWT 同步记录。
- 每个快照 112 B，缓冲区头部 64 B，共 114752 B，位于 `.sram2`，不侵占末端核间邮箱。
- 速度稳态判据保持最大误差 ≤50 rpm、平均 ≤25 rpm；电流采样峰值 <3 A，ISR 执行时间 <50 µs，
  ADC overflow 不增加。诊断 ISR 在越界时直接关断；单点测试有 12 s 硬期限。
- 改速每段 8 s、共约 24 s，因此该诊断镜像的硬期限单独设为 32 s；其余电流、ADC、时序判据不变。
- 主机 `finally` 发送 STOP 并确认 `state=idle`；之后才接 SWD，先读 GPIO23 为低，
  再额外清低并暂停导出。没有在功率级使能时暂停 MCU。

## 500 rpm 可逆与重复对照

窗口长度均为 1024 点。高频角度纹波是去趋势后 Hann 功率谱积分得到的输出 RMS，
不是有编码器参考的真实转子角误差。

| 实测量 | A1 原版 | B1 修正版 | A2 回切原版 | B2 重复修正版 |
| --- | ---: | ---: | ---: | ---: |
| 原始 PLL 速度标准差 / rpm | 821.60 | 142.88 | 776.82 | 147.96 |
| 控制角 RMS，200～3000 Hz / 电角度° | 2.180 | 0.1068 | 1.758 | 0.1436 |
| 控制角 RMS，200～9900 Hz / 电角度° | 2.180 | 0.1162 | 1.758 | 0.1512 |
| 滤波速度标准差 / rpm | 19.95 | 24.17 | 10.56 | 11.38 |
| Iq RMS，200～3000 Hz / A | 0.0269 | 0.0305 | 0.0275 | 0.0247 |
| 全轮 ADC 相电流采样峰值 / A | 1.452 | 1.260 | 1.198 | 1.243 |
| ISR 执行时间观测峰值 / µs | 26.833 | 27.343 | 25.628 | 27.758 |

两组 B 相对两组 A 的原始速度标准差降低约 **80.95%～82.61%**，
控制角 200～3000 Hz 输出纹波降低约 **91.83%～95.10%**。
回切 A 后大纹波恢复，再切 B 后重新降低，支持改善来自这次控制算法改动。

原版主要速度纹波在约 742～801 Hz；修正版剩余开关纹波主要在约 4.9～5.0 kHz。
上表也给出覆盖到 9.9 kHz 的角度 RMS，没有仅靠排除高频来制造改善。

## 修正版启动、改速和停机

`500→600→500 rpm`，每段保持 8 s，最后 3 s 的串口估算速度判据：

| 目标 / rpm | 最大误差 / rpm | 平均绝对误差 / rpm |
| --- | ---: | ---: |
| 500 | 30 | 20.00 |
| 600 | 11 | 4.27 |
| 500 | 22 | 10.91 |

该轮电流采样峰值 1.346 A，ISR 峰值 28.4425 µs，ADC overflow 为 0。
高频缓冲在 9 s 时采到的窗口位于第一次改速之后，故不纳入稳态抖动 A/B 比较。
全部七轮（六轮单点对照及一轮改速）均通过电流、时序、无 overflow、跟踪及停机检查。

## 能得出与不能得出的结论

**能确认：** 当前 500/800 rpm 的短时工况下，直接注入反馈显著降低原始 PLL 和控制角的
高频输出纹波；修改未阻止启动、改速和停机。

**不能宣称：** 所有速度波动已解决，或真实转矩、噪声、温升、效率已经改善。
滤波速度在这些短窗中并未一致改善，Iq 高频纹波也没有一致下降；硬开关剩余纹波仍存在。
没有独立轴速/轴角传感器，控制角输出纹波不等于转子角误差。
本次未覆盖实板反转、堵转、带载、温升、长期、热重启或 CAN 通信压力。

DWT 是 ISR 入口时间戳，不是硬件 ADC 转换时刻；实际入口间隔存在变化，详见 `results.json`。
名义 20 kHz 的 FFT 分辨率为 19.53125 Hz。ISR 峰值为观测执行时间，不是严格 WCET 或总延迟保证。
